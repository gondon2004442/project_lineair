# Стенды

Проверки, которые гоняют настоящую сборку в настоящем браузере и
отвечают числами. Игре они не нужны: `playwright` в зависимости проекта
не входит и берётся тот, что стоит в системе.

```
npm run build
npm run preview &          # отдаёт сборку на 127.0.0.1:4173
node tools/fullrun.mjs
```

Адрес можно переопределить: `LINEAIR_URL=http://127.0.0.1:5173`.

## fullrun.mjs — сквозной прогон

Играет забег от вестибюля до решения: ищет проход по сетке плитки,
входит в проёмы ходом, расстреливает мебель, когда упёрся, сдаёт
аттестации прицелом и телекинезом, подбирает печать руками, делает крюк
за делом спасённого и входит в шахту ногами. Присваиваний в мир нет —
кроме снятия штата по прочности: стенд проверяет проходимость
вертикали, а не умение уворачиваться.

```
node tools/fullrun.mjs                 # пять посевных по умолчанию
node tools/fullrun.mjs 4242 7777 11    # свои посевные
```

Выход ненулевой, если нашлась беда или страница выбросила ошибку.
Этим стендом найдены: снаряд, гаснущий о пустоту натурной части, и
помещения, из которых не выйти, когда мебель встала поперёк прохода.

## review.mjs — проход по бедам

Короткие проверки того, что уже ломалось: распоряжения, пережившие
начальника; мишень в пустоте; падение по кругу; проём в самого себя;
снятые, которые продолжают стрелять; назначение, которое не кончается;
счёт, который удваивается на возврате; дело, которое подбирается
дважды; снаряд, гаснущий о дыру. Плюс цена шага.

```
node tools/review.mjs
```

Выход ненулевой, если нашлась хоть одна беда.

## determinism.mjs — один seed, один забег

Два мира с одной посевной гоняются одинаковым вводом и должны сойтись
до последнего числа; третий с другой посевной — разойтись.

```
node tools/determinism.mjs [шагов]
```

## content.mjs — правки попадают в живые числа

Проверяет, что путь каждой правки предмета и распоряжения есть в
tuning, что он число и что выданный предмет его двигает; что
распоряжение собирается своим же набором приложений; что у инвентаря
есть эффект с откатом.

```
node tools/content.mjs
```

## registry.mjs — данные сходятся между собой

Должность, которой нет в списке POSTS, не ломает сборку: сотрудник
молча получает чужой силуэт и латинский заголовок. Так однажды и вышло
с начальником отдела кадров. Стенд сверяет ссылки между реестрами —
этажи, расписания, шаблоны, испытания, исходы, формы, субъекты — и
проверяет, что каждая должность и правда встречается в игре.

```
node tools/registry.mjs
```

## arsenal.mjs — что делает каждая форма

Обойма, запас, перезарядка и урон в секунду по замороженной ставке с
трёх дистанций, плюс время на снятие инспектора. Форма, которая не
наносит урона вовсе, объявляется бедой — так нашлось, что зарядная
стреляет отпусканием, а не нажатием.

```
node tools/arsenal.mjs
```

## counters.mjs — стойки делают то, что обещают

Для каждого вида стойки: приглашение не пустое, цена названа, подача
меняет ровно то, что написано в предложении, окошко после этого
закрывается и второй раз не принимает; без талонов не принимает и
ничего не трогает.

```
node tools/counters.mjs
```

## threat.mjs — что делает каждая должность

Одна ставка против неподвижного субъекта, пятнадцать секунд: урон,
снаряды, листы распоряжений, шкафы на ходу, пройденный путь и
дистанция, на которой она держится. Должность, не делающая ВООБЩЕ
ничего, объявляется бедой — не наносить урона по замыслу можно
(стажёр не атакует вовсе), но стоять истуканом нельзя.

```
node tools/threat.mjs
```

## all.mjs — все стенды подряд

```
npm run stands
```

Запускает каждый стенд своим процессом, печатает беды и сводит итог.
Выход ненулевой, если хоть один нашёл беду.
