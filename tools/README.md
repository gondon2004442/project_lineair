# Стенды

Проверки, которые гоняют настоящую сборку в настоящем браузере и
отвечают числами. Игре они не нужны: `playwright` в зависимости проекта
не входит и берётся тот, что стоит в системе.

```
npm run build
npm run preview &          # отдаёт сборку на 127.0.0.1:4173
node tools/fullrun.mjs
```

Адрес можно переопределить: `LINEAIR_URL=http://127.0.0.1:5173`.

## fullrun.mjs — сквозной прогон

Играет забег от вестибюля до решения: ищет проход по сетке плитки,
входит в проёмы ходом, расстреливает мебель, когда упёрся, сдаёт
аттестации прицелом и телекинезом, подбирает печать руками, делает крюк
за делом спасённого и входит в шахту ногами. Присваиваний в мир нет —
кроме снятия штата по прочности: стенд проверяет проходимость
вертикали, а не умение уворачиваться.

```
node tools/fullrun.mjs                 # пять посевных по умолчанию
node tools/fullrun.mjs 4242 7777 11    # свои посевные
```

Выход ненулевой, если нашлась беда или страница выбросила ошибку.
Этим стендом найдены: снаряд, гаснущий о пустоту натурной части, и
помещения, из которых не выйти, когда мебель встала поперёк прохода.

## review.mjs — проход по бедам

Короткие проверки того, что уже ломалось: распоряжения, пережившие
начальника; мишень в пустоте; падение по кругу; проём в самого себя;
снятые, которые продолжают стрелять; назначение, которое не кончается;
счёт, который удваивается на возврате; дело, которое подбирается
дважды; снаряд, гаснущий о дыру. Плюс цена шага.

```
node tools/review.mjs
```

Выход ненулевой, если нашлась хоть одна беда.

## determinism.mjs — один seed, один забег

Два мира с одной посевной гоняются одинаковым вводом и должны сойтись
до последнего числа; третий с другой посевной — разойтись.

```
node tools/determinism.mjs [шагов]
```
