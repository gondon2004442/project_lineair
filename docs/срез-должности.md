# Срез: должности

План следующего вертикального среза. Написан заранее, чтобы работа
возобновилась без пересборки контекста. Порядок пунктов — порядок работы.

## Что должно получиться на ощупь

Заходишь на участок. Видишь три силуэта с табличками. Пока Регистратор за
столом жив, выбитые ставки закрываются: стажёры получают повышение, штат
добирается до квоты. Убил Регистратора первым — участок перестаёт
восполняться и превращается в обычную зачистку. Не убил — воюешь с кадровым
отделом.

Один срез = играбельно. Ревизор, Курьер и Заведующий сюда не входят:
Ревизор завязан на телекинез (Шаг 5), Курьер — на связь между участками,
Заведующий — босс. Их данные в файл не вписываем, пока нет поведения.

## Принятое решение, которое стоит подтвердить

Стажёр занимает освободившуюся вакансию **только пока жив Регистратор** —
повышение это приказ, а не самодеятельность. Иначе штат восполняется сам
собой, и «убей Регистратора первым» перестаёт быть выбором. Если задумано
иначе — скажи, разворачивается в одну строчку условия.

## 1. Данные

### `src/data/posts.ts` — новый файл

Описание должности как данные: чем рисуется, что на табличке, сколько
здоровья. Поведение ищется по `id`.

```
{ id, title, hp, radius, shape, plateMarks, color }
```

- `plateMarks` — число насечек на табличке: 0 стажёр, 1 инспектор,
  2 регистратор. Табличка на груди плюс форма силуэта — вся система
  телеграфов, туториал не нужен.

### `src/data/staffing.ts` — дополнить

Расписания получают настоящий состав вместо пяти одинаковых инспекторов:

```
patrol:      инспектор 2 (prio 2), стажёр 2 (prio 3)
registry:    регистратор 1 (prio 1), инспектор 3 (prio 2), стажёр 4 (prio 3)
head_office: регистратор 1, инспектор 5, стажёр 4
lobby:       пусто
```

`priority` уже есть в формате: меньше число — раньше закрывают вакансию.

## 2. Компоненты и учёт вакансий

- `enemyC` разбирается на общий `staffC` (`post`, `title`, `priority`)
  и отдельные компоненты поведения: `internC`, `inspectorC`, `registrarC`.
- В `World` появляется `roster`: по каждой должности участка `quota`
  и `occupied`. Вакансия = `quota - occupied`.
- Смерть сотрудника уменьшает `occupied`. Двери открываются, когда на
  участке никого не осталось **и** вакансий закрывать некому.

Систему учёта держать отдельно от систем поведения:
`src/systems/staff.ts` — вакансии, приказы, добор.

## 3. Поведение должностей

### Стажёр — `src/systems/postIntern.ts`

- Не атакует. Ходит по маршруту: список свободных клеток, выбранных из
  комнатного PRNG, с паузой на точке.
- Получив приказ, идёт к точке вакансии; дойдя, переназначается: меняются
  компонент поведения, табличка, прочность.
- Телеграф: пустая табличка. Во время перехода — мигание таблички.

### Инспектор — `src/systems/postInspector.ts`

Переписывается нынешний враг. Именно это ломает старую расстановку ощущений,
поэтому идёт вместе с новыми ручками.

- Движение **только по осям**: выбирает ось, идёт по ней, поворачивает на 90°.
  Проверять тестом: у скорости всегда одна из компонент нулевая.
- Огонь **строго по такту**: на участке один метроном, все инспекторы бьют
  по доле. За такт до выстрела — жёлтая вспышка таблички.
- Читается идеально, убивается позиционированием: встань вне его оси.

### Регистратор — `src/systems/postRegistrar.ts`

- Сидит за столом: неподвижен, стол — блок под ним.
- Веер картотечных карточек: `fanCount` пуль в раскрыве `fanSpread`,
  по своему интервалу.
- Закрывает вакансии по `priority`: сначала ищет стажёра для повышения,
  если стажёров нет — добирает штат со стороны запертой двери с задержкой.
- Телеграф: над ним счётчик незакрытых ставок.

## 4. Ручки

Новые группы в `TUNING` и в панели: «СТАЖЁР», «ИНСПЕКТОР», «РЕГИСТРАТОР».

- стажёр: скорость, пауза на точке, время перехода на должность
- инспектор: скорость по оси, интервал метронома, доля с выстрелом,
  упреждение телеграфа, пуль за такт
- регистратор: прочность, карточек в веере, раскрыв, интервал веера,
  задержка повышения, задержка добора, потолок добора за участок

Потолок добора обязателен: без него живой Регистратор делает участок
бесконечным.

## 5. Оверлей

- «ВАКАНСИЙ» в левом блоке рядом со «ШТАТ НА УЧАСТКЕ»
- счётчик над Регистратором
- в схеме этажа участок с живым Регистратором помечается

## 6. Как проверять

1. Убить Регистратора первым: вакансии не закрываются, участок зачищается
   как обычный, добора нет.
2. Оставить Регистратора: выбить инспекторов, убедиться, что штат
   восстанавливается до квоты и **не выше** её, а добор упирается в потолок.
3. Инспектор: у скорости всегда одна нулевая компонента.
4. Метроном: интервалы между выстрелами равны, разброс по кадрам нулевой.
5. Стажёр не наносит урона ни при каких условиях.
6. Двери: участок с одними стажёрами всё равно зачищается.
7. Детерминизм: тот же seed — тот же хеш положений и здоровья.
8. Никто не появляется в бетоне, включая добор.

## 7. Порядок работы

1. `posts.ts`, разбор `enemyC` на `staffC` + компоненты поведения, учёт
   вакансий. Инспектор пока со старым поведением — проект остаётся играбельным.
2. Инспектор: оси и метроном. Ручки. Проверка 3 и 4.
3. Стажёр: маршрут, приказ, переназначение. Проверка 5.
4. Регистратор: веер, закрытие вакансий, добор, потолок. Проверки 1, 2, 6.
5. Оверлей, схема, README. Проверки 7 и 8. Коммит.
