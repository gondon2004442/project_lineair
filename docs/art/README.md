# Референс по виду

Офисный кит, от которого отталкивается внешний вид объекта.

- `lineair_office.py` — скрипт Blender, собирающий кит и комнату-опенспейс.
  Запуск: `blender -b --factory-startup --python lineair_office.py -- [kit|room|both]`
- `office_kit_contact.png` — контактный лист кита
- `office_bullpen.png` — опенспейс целиком
- `lineair_office.blend` — сцена

Палитра в игре взята из этого скрипта один в один (`PAL` в нём,
`src/palette.ts` в игре), поэтому цвета сходятся без подгонки на глаз.

Что кит задал игре напрямую:

- **ковролин** вместо голого бетона, со швами по границам плиток;
- **стены с панелью**: ореховая обшивка до полутора метров, бетон выше,
  латунный профиль между ними. Сверху видна обшивка, обращённая в комнату;
- **стеклянные перегородки** — в ките подписано «бьётся», поэтому
  разрушаемая перегородка в игре стала именно стеклом, а не бетоном;
- **дверь**: тёмный проём, деревянный наличник, жёлтая разметка на полу
  и красная лампа над ним — ровно то, чем в игре показан замок;
- **кулер и фикус**, кресло, стеллаж с папками — виды мебели на участках.
